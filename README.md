# pygame_fightermanaging

## ゲーム設計仕様書：管理職はつらいよ 〜亜人パーティ・マネジメント〜
### プロジェクト概要
#### コンセプト
「本能で動く部下（亜人）の不始末は、リーダー（人間）の責任」
* 本作は、地域密着型のローグライク・マネジメントRPGです。
* プレイヤーは物理的に無力な「人間」の司令塔となり、強力ですが本能に忠実すぎる「亜人」の部下たちを率いてクエスト攻略を目指します。
* 最大の敵はモンスターではなく、部下が勝手に引き起こす「不祥事」。
* 彼らの尻拭いをし、地域住民に土下座し、限られた予算で人件費をやりくりする「中間管理職の悲哀」をゲーム体験へと昇華させます。

### ゲームフロー
1. 準備フェーズ
   * ギルドでクエスト（採集、討伐、護衛等）を受注。
   * 前金で部下との契約、食料や野営道具を揃えます。
   * 荷物の大半は部下に預けることになりますが、預けすぎには注意が必要です。
2. マップ進行
   * 左端の拠点から右端の目的地へ、プロットを辿ります。
   * 集落:
     * 売買や宿泊が可能。
     * 評判が悪いと入村を拒否されたり、部下が勝手に略奪を始めることも。
   * 環境（森・廃墟等）: 
     * 魔物との戦闘や、他パーティとの遭遇が発生。
     * 評判が良ければ支援を受けられますが、悪ければ「制裁」の対象になります。
3. 戦闘と野営
    * 接敵時はリーダーが指示を出し、部下が独自に判断して動きます。
    * 戦闘後は負傷の治療、素材の剥ぎ取り、そして一晩を明かす「野営」を行い、態勢を整えます。
4. クエスト完了と周回
    * 目的地に到達するとクエストクリア。実績だけでなく「部下たちの価値観」に基づいた採点が行われます。
    * 同じエリアを3〜5回周回する中で、過去のあなたの選択（善行や略奪）が地域の治安や物価に累積して跳ね返ってきます。

### 勝利・敗北条件
   * 勝利：最終エリアボスの撃破、あるいは特定目的の達成。
   * 敗北（ゲームオーバー）：司令塔（人間）の死亡、全メンバーの離脱、あるいは資金・食料の枯渇による詰み。

### キャラクターシステム
1. 司令塔（プレイヤー：人間）
   * 直接戦闘能力は皆無。指示とアイテム管理、責任（謝罪）の全権を担う。
2. 亜人メンバー（種族・個性）
   * 種族：狼（連携）、猫（気まぐれ・盗み）、牛（頑丈・大食い）、鳥（プライド・偵察）など。
   * 個性：習性を強化する「潔癖症」「守銭奴」「魔眼持ち」などの複数の特性。
3. ベースパラメータ
    |パラメータ|説明|備考|
    |:-|:-|:-|
    |STR|力|特定の武器の使用条件。持てる荷物の重さ、一部武器の威力に影響。|
    |DEX|器用さ|特定の武器、道具の使用条件。相手から強奪しやすさ。|
    |AGI|素早さ|戦闘の行動回数に影響。|
    |INT|賢さ|魔法の使用条件。詠唱速度。|
    |LUK|幸運|未定|
    |VIT|生命力|物理ライフに影響|
    |MEN|精神力|精神ライフに影響|
    |SOL|霊力|魂ライフに影響|
4. 抵抗力
    |パラメータ|説明|備考|
    |:-|:-|:-|
    |HP|物理ライフ|物理的なライフ。0になると体が動かせなくなる。(VIT×10)|
    |MP|精神ライフ|精神的なライフ。0になると動く気力がなくなる(MEN×10)|
    |SP|魂ライフ|魂的なライフ。0になると成仏して動かなくなる。(SOL×10)|
    |P-RES|物理抵抗|物理的な攻撃に対する抵抗。|
    |M-RES|精神抵抗|精神的な攻撃に対する抵抗。|
    |S-RES|魂抵抗|霊的な攻撃に対する抵抗。|
5. 管理ステータス
    |パラメータ|説明|備考|
    |:-|:-|:-|
    |Loyalty|忠誠度|リーダーに対する忠誠度。低いほど命令を聞かない。|
    |Favorability|好感度|メンバー同士での好感度。各種行動に影響。|
    |Wildness|野生度|本能的な行動をしやすくなる。|
    |Hunger|空腹度|行動と共に低下。減りすぎると忠誠度が下がり、本能的な行動を起こしやすくなる。|
    |Charm|愛嬌|多少の粗相を許してもらえやすくなる。|
    |Drive|本能昂ぶり|未定|

### 戦闘システム
1. フィールドと配置
   * 9×3グリッド。
   * 左3列が自陣、右3列が敵陣。中央が中立地帯。
2. 行動選別（ウェイト抽選方式）
   * 固定ターン制ではなく、AGIに基づいた「選ばれやすさ（重み）」で行動主体をリアルタイム抽選。
   * 重み = AGI/(x^n) 。小数点切り捨て。
   * xは調整値(1より大きい)
   * nはフェーズ内行動回数。
   * 行動するほど次回の抽選率が下がる。
3. ダメージ計算
   * 除算モデル：
   * 攻撃系統（P, M, S）に対応するAtkとResを使用。
4. 司令フェーズとAIのブレ
   * 司令：殲滅、強奪、撤退、待機を指示。
   * 無視判定：野生度が高いほど指示を無視し、本能的な行動（トドメ、強奪、独断後退）をとる。
   * 対象選びのブレ：好感度の高い相手を優先回復したり、嫌いな相手を「誤射（悪意）」したりする。

### 社会・環境システム
1. 集落パラメータ
   * POP（人口）、FOOD（食料）、WLT（富）、SEC（治安）、情報伝達力、属性バイアス。
2. 略奪と謝罪
   * 不祥事：メンバーが勝手に盗みや暴行を働く。
   * 謝罪：利益の数倍の金銭、または奉仕労働（時間経過＋デバフ）による責任の補填。
   * 放置：指名手配となり、他パーティからの強襲リスク、次周回の物価高騰を招く。

### 難易度とやり込み要素
   * イージー：高予算、高適正メンバー、幼馴染割引。
   * ハード：低予算、不適正雇用（戦わない僧侶、盗みたい盗賊等）、流行病、飢饉、蛮族。
   * 不祥事図鑑：種族や個性の組み合わせで発生する特殊な不祥事の収集。
